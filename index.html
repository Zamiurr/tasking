Cross-Device Cloud Sync

Zero-secret sync stored only in your browser — safe for public GitHub repos

How GitHub Gist Sync works:

Create a Personal Access Token on GitHub with only the gist permission. This app creates a private Gist (project-payout-tracker-data.json) and auto-syncs whenever you edit tasks or payouts.

Firebase Realtime Database URL:

Paste your Realtime Database root URL (e.g., https://my-app-default-rtdb.firebaseio.com). Data syncs to /project_payout_tracker_v2.json.

1-Click Device Pairing (Phone / Tablet / Laptop)

Copy the Magic Sync Link and open it on your phone—it will automatically configure sync and strip the key from the URL bar for security.

Host on GitHub Pages in 60 Seconds

  1. Create a new GitHub repository (e.g., payout-tracker).
  2. Click Add file → Create new file, name it index.html, paste this entire code, and click Commit changes.
  3. Open your repo's Settings → Pages, set Source to Deploy from a branch, select main / / (root), and click Save.
  4. Open your live username.github.io/payout-tracker link, click Cloud Sync, and connect a GitHub gist token to sync between PC and phone!
